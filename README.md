# AP World History Unit 2 Mastery

An interactive, responsive study app for AP World History Unit 2: **Networks of Exchange (c. 1200–1450 CE)**. Built with React, TypeScript, Vite, Tailwind CSS, Framer Motion, Recharts, and React Router. No backend or account is required; study history is saved in browser local storage.

## Run locally

```sh
npm install
npm run dev
```

Open the local URL printed by Vite. To create and preview a production build:

```sh
npm run build
npm run preview
```

## Study modes

- **Overview:** mastery, XP, streaks, study activity, and badge progress.
- **Learn:** six guided field guides; route map, Buddhism spread activity, Mongol phases, disease timeline, and seasonal monsoon simulator.
- **Flashcards:** all 17 key terms, network filters, card flipping, and known/review-again tracking.
- **Practice:** 351 generated multiple-choice questions plus 20 true/false items, topic and difficulty filters, answer feedback, and AP reasoning tips.
- **Play:** term matching, timeline ordering, map identification, and a cause-and-effect challenge.
- **AP exam:** 20 SAQs, 15 LEQs, and 15 DBQ prompts with a writing area, self-check rubric, and local response saving.

The multiple-choice bank uses 39 Unit 2 fact sets with alternate question stems and three difficulty labels. User progress and responses are kept in local storage on the current browser/device. Clear site data to reset local study history.
