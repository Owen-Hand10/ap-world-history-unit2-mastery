# AP World History: Modern Learning Platform

An interactive, responsive study app for the complete AP World History: Modern course. Explore nine units from **The Global Tapestry (1200–1450)** through **Globalization (1900–present)**. Built with React, TypeScript, Vite, Tailwind CSS, Framer Motion, Recharts, and React Router. No backend or account is required; study history and writing responses are saved in browser local storage.

## Run locally

```sh
npm install
npm run dev
```

Open the local URL printed by Vite. To create and preview a production build:

```sh
npm run build
npm run preview
```

## Course navigation

- **Dashboard:** course overview, the original Unit 2 route map and study activity, achievements, and links to all nine units.
- **Units 1–9:** overview, interactive timeline, major developments, key concepts and vocabulary, flashcards, guided lessons, practice quizzes, AP-style MCQs, SAQs, LEQs, review games, and unit progress.
- **Exam Review:** historical thinking tutorials, adaptive missed/weak-topic practice, DBQ practice, and a countdown to the estimated May 2027 exam window.
- **Vocabulary:** searchable all-unit glossary, flashcard mode, and matching mode.
- **Practice Tests:** a timed 55-question, 95-minute full-course MCQ practice set.
- **Progress:** course and unit accuracy, XP, streaks, known terms, and achievement milestones.

Each unit includes an AP-aligned study guide, a multiple-choice set with one question per key term (to avoid repeating the same answer through near-identical prompts), 25 SAQs, and 15 LEQ practice prompts. Across the course, multiple-choice items use stimulus, map, image, comparison, continuity/change, causation, and historical-interpretation formats. The course-wide collection also includes 10 DBQ exercises with practice document summaries, sourcing guidance, and rubric breakdowns. The study-guide objectives are original paraphrases aligned to the [College Board AP World History: Modern Course and Exam Description](https://apcentral.collegeboard.org/media/pdf/ap-world-history-modern-course-and-exam-description.pdf); students can also open free [OER Project World History 1200 readings](https://www.oerproject.com/World-History-1200) from each unit. The original Unit 2 lessons, flashcards, timeline/map activities, games, AP prompts, and progress data remain available.

The DBQ dossiers are newly written practice summaries, not reproductions of historical primary-source documents. User progress and responses are kept in local storage on the current browser/device. Clear site data to reset local study history.
